home-portal is installed and running

Open http://127.0.0.1:8080 and sign in as admin. The password is in
~/.config/home-portal/initial-password

The configuration is ~/.config/home-portal/home-portal.toml; the portal starts at every login.

When every service on the local network shows as down, allow home-portal in System Settings → Privacy & Security → Local Network.

Another user of this Mac sets the portal up with /usr/local/libexec/home-portal/setup. To remove it: sudo /usr/local/libexec/home-portal/uninstall.
